# Beecrowd Solutions

## 💻 Sobre

Este repositório contém minhas soluções para desafios do Beecrowd (antigo URI Online Judge). Aqui
compartilho meu progresso na prática de lógica de programação e resolução de problemas.

## 🎯 Objetivos

- Melhorar minha habilidade de resolver problemas através da prática constante.
- Aprimorar minha capacidade de transformar problemas complexos em código funcional.
- Compartilhar aprendizados e contribuir com a comunidade de programadores.

## 📁 Organização

Os exercícios estão organizados por categoria, seguindo a estrutura do Beecrowd, e nomeados de
acordo com o ID do problema na plataforma.

### 📌 Categorias

- [**Iniciante**](caminho/para/pasta) - Problemas básicos para quem está iniciando na programação.
- [**Ad-Hoc**](caminho/para/pasta) - Simulação, Datas e problemas Ad-Hoc em geral.
- [**Strings**](caminho/para/pasta) - Palíndromos, Frequência, LCS, Manipulação de Strings.
- [**Estruturas e Bibliotecas**](caminho/para/pasta) - Filas, Pilhas, Ordenação, Mapas.
- [**Matemática**](caminho/para/pasta) - Sistemas Numéricos, Números Primos, BigInteger.
- [**Paradigmas**](caminho/para/pasta) - Programação Dinâmica, Busca Binária, Gulosos, Backtracking.
- [**Grafos**](caminho/para/pasta) - Flood Fill, MST, SSSP, DAG, Fluxo Máximo, Árvores.
- [**Geometria Computacional**](caminho/para/pasta) - Pontos e Linhas, Polígonos.
